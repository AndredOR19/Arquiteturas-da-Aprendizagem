A fonte única de cadastro normativo é [base-curricular/catalogo.json](../../base-curricular/catalogo.json). Não duplicar documentos oficiais aqui nem promover planos de colegas a normas oficiais.

Para incorporar um documento, obter o arquivo autorizado/oficial, conferir órgão, título, etapa, versão, URL/origem, vigência e hash e atualizar o catálogo. Se disponível apenas um link ou uma citação, manter estado explícito. Habilidades presentes nos cinco documentos recebidos são referências declaradas nesses planos; sua correspondência normativa ainda exige conferência.
