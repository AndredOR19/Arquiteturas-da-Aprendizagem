# Contribuições de professores

Um professor entra no acervo por contribuição revisada e autorização de acesso próprias; esta pasta não concede permissões. Identificar responsável profissional estável, escola/componente e fonte de autoria. Não publicar contatos pessoais ou dados de estudantes para montar cadastro de participantes.

O acervo inicial é organizado pelo Prof. André de Oliveira Rodrigues (`andre-rodrigues`). Os planos podem indicar outros regentes/autores, preservados em seus metadados. Indicação no documento não significa ingresso do autor como colaborador do projeto ou aceite de sua parte.

Cada contribuição deve seguir [COMO_CADASTRAR](../COMO_CADASTRAR.md), as regras do repositório e os dois fluxos. Compartilhar planos gerais e normas comuns sem misturar fontes de escolas, períodos e turmas. Materiais institucionais restritos e PEIs preenchidos nunca devem entrar na branch pública.
