# Guias e roteiros de mediação

Cadastrar aqui somente guias gerais que o autor autorize compartilhar, sem dados de estudantes, laudos ou informações restritas. Preservar título, autoria, versão, componente, finalidade e relação com planos/aulas por IDs.

Guia docente ou gabarito reservado permanece em canal restrito. Este diretório público não deve conter senhas, respostas reservadas nem links de acesso a prontuários. Arquivo fora do GitHub Pages continua visível no GitHub. Nenhum guia novo foi recebido no lote dos cinco documentos; as orientações operacionais do acervo estão no diretório superior.
