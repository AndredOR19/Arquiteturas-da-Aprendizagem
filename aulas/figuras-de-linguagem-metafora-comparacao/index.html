Toque nos desenhos para ouvir seu som. Use “Ouvir explicação” para conhecer a relação.
Comparação: O Sorriso
Seu sorriso é como o sol!
A palavra como aproxima sorriso e sol. Em uma mensagem afetuosa, os dois sugerem alegria e luminosidade.
Pista: a semelhança aparece com um conectivo.
Metáfora: A Memória
Minha memória é um álbum.
O álbum representa lembranças guardadas. Não quer dizer que a memória tenha folhas: uma imagem empresta sentido à outra.
Pista: a aproximação é figurada, sem como.
Ideias: As Sementes
As ideias são sementes.
Sementes podem crescer quando recebem cuidado. A frase sugere que ideias também podem se desenvolver: essa é a relação que cria a metáfora.
Curiosidade: uma mesma imagem pode criar sentidos diferentes conforme o contexto.
Os sons começam somente quando você toca nos desenhos.
