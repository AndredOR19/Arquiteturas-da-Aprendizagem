# Roteiro de observação em sala — validação prática do protocolo de linguagem clara (seção 38.9)

O validador automático confere apenas regras objetivas. **Só o estudante diz se entendeu.** Este roteiro registra essa verificação; sem ele, a aula fica em "revisão humana pendente" mesmo com zero bloqueios.

## Para cada atividade observada

Abra a atividade e, **antes de explicar qualquer coisa**, pergunte:

> **"Olhe esta atividade e me diga: o que você precisa fazer?"**

Anote a resposta com as palavras do estudante e marque:

| Pergunta de domínio | Sim | Parcial | Não |
|---|---|---|---|
| 1. Ele(a) disse o que precisa fazer sem ajuda? | | | |
| 2. Ele(a) sabe onde está a informação necessária (situação, números, figura)? | | | |
| 3. O exemplo com outro caso ajudou a fazer, sem entregar a resposta? | | | |
| 4. Depois de um erro, a explicação em linha permitiu tentar de novo sozinho(a)? | | | |
